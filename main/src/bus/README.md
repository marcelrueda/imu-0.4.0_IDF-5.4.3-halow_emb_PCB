## Descripción de Archivos
Este directorio contiene la implementación de los buses de comunicación.

- **bus_i2c.c / .h:** Implementación y configuración del bus I2C para la comunicación con periféricos compatibles.
- **bus_spi.c / .h:** Implementación y configuración del bus SPI, optimizado para alta velocidad.
