## Descripción de Archivos
Gestión de recursos internos del sistema y tiempo.

- **system_metrics.c / .h:** Monitoreo del consumo de memoria, niveles de batería y estado del procesador.
- **time_ntp.c / .h:** Sincronización de hora mediante el protocolo Network Time Protocol.
- **time_utils.c / .h:** Herramientas para el manejo de formatos de tiempo y calendarios.
