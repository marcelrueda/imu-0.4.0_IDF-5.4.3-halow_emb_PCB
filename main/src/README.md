## Descripción de Archivos
Este es el directorio raíz de la lógica del firmware.

- **main.c:** Punto de entrada principal de la aplicación, inicialización de tareas y orquestación del sistema.
- **main.h:** Definiciones globales, macros y prototipos de funciones principales.
- **bus/:** Controladores para protocolos de comunicación (I2C, SPI).
- **common/:** Herramientas y funciones de utilidad comunes.
- **image/:** Gestión de imágenes y recursos visuales.
- **imu/:** Controladores y procesamiento de datos de sensores inerciales.
- **net/:** Configuración y protocolos de red (WiFi, HaLow, MQTT, etc.).
- **peripherals/:** Controladores de periféricos como pantalla, tarjeta SD y sensores analógicos.
- **sys/:** Métricas del sistema y gestión del tiempo.
