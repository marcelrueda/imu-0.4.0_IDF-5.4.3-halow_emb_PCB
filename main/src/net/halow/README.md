## Descripción de Archivos
Archivos de soporte específicos para la tecnología Wi-Fi HaLow de Morse Micro.

- **mm_app_common.c / .h:** Funciones comunes y estructuras compartidas por las aplicaciones HaLow.
- **mm_app_loadconfig.c / .h:** Carga de configuraciones específicas para el módulo HaLow.
- **mm_app_regdb.c / .h:** Base de datos regulatoria para el cumplimiento de frecuencias según la región.
