## Descripción de Archivos
Controladores para hardware externo y sensores analógicos.

- **device_display.c / .h:** Manejo de la pantalla para la interfaz de usuario.
- **device_sd.c / .h:** Gestión del almacenamiento en tarjeta SD (logs, archivos de configuración).
- **sensor_analog.c / .h:** Lectura y procesamiento de señales analógicas mediante ADC.
